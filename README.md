# Live Translator

Mod de tradução em tempo real para tModLoader.

Este é o repositório oficial do projeto e, por enquanto, concentra o sistema de patches comunitários usado pelo próprio mod.

## Patches da comunidade

Para compartilhar uma tradução:

1. Exporte o patch pelo Live Translator.
2. Abra o formulário **Enviar tradução comunitária** em Issues.
3. Anexe o arquivo `.json` exportado.
4. Envie.

O Live Translator consulta as Issues abertas com a label `live-translator-patch` e mostra os patches disponíveis dentro do próprio mod.

## Formato do patch

O formato atual está documentado em [PATCH_SCHEMA.md](PATCH_SCHEMA.md).

O nome do mod, versão, idioma e traduções vêm do próprio JSON exportado pelo Live Translator. A autoria vem da conta GitHub que abriu a Issue, e selos como `verified` vêm das labels da Issue.
